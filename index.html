TTGO LoRa32 v2.1 avec carte microSD

Firmware 4.0.1RXT - 7 septembre 2026 - ESP32 / 433 MHz

Navigateur non compatible. Utilisez Chrome, Edge ou Chromium. L'accès au port USB n'est pas autorisé.
La configuration sera effacée. Téléchargez d'abord sa sauvegarde JSON depuis la WebConfig. Après le flash, reconnectez-vous au point d'accès de l'iGate et restaurez cette sauvegarde.

Installation

  1. Fermez le moniteur série et tout logiciel utilisant le port USB.
  2. Reliez la carte au PC avec un câble USB de données.
  3. Cliquez sur Installer le firmware, puis choisissez le port série de l'ESP32.
  4. Après le redémarrage, ouvrez http://192.168.4.1 depuis le Wi-Fi de configuration de la station.

Contenu de cette version

  • journal des paquets sur carte microSD ;
  • télémétrie APRS RX / Relay / Drop ;
  • télémétrie RXT multi-sauts de N7UV ;
  • traitement exact des jetons WIDE2-n.
