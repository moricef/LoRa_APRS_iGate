Installation du firmware

Connectez la carte par USB, puis choisissez exactement le modèle utilisé.

Navigateur non compatible. Utilisez Chrome, Edge ou Chromium. L'accès au port USB n'est pas autorisé.

Navigateur non compatible. Utilisez Chrome, Edge ou Chromium. L'accès au port USB n'est pas autorisé.

QRP Labs LightGateway Plus 1.0

Navigateur non compatible. Utilisez Chrome, Edge ou Chromium. L'accès au port USB n'est pas autorisé.

Firmware 4.0.2RXT - 21 septembre 2026 - ESP32 / ESP32-S3 / 433 MHz

Avant l'installation :
  • Sauvegardez la configuration JSON depuis la WebConfig.
  • Utilisez Chrome, Edge ou Chromium.
  • Fermez le moniteur série et tout logiciel utilisant le port USB.
  • Vérifiez soigneusement le modèle choisi avant de lancer l'installation.
  • Laissez l'effacement désactivé pour conserver la configuration.
  • Activez l'effacement uniquement pour une installation propre ou pour réparer une flash endommagée.

Contenu de cette version

  • Journal des paquets sur carte microSD
  • Télémétrie APRS RX / Relay / Drop
  • Télémétrie RXT multi-sauts de N7UV
  • Flux LoRa APRS JSON versionné avec reprise d'historique
  • Snapshot JSON des dix dernières réceptions pour les tableaux de bord
  • Traitement exact des jetons WIDE2-n
Après un effacement :
  • Connectez-vous au point d'accès Wi-Fi de la station.
  • Ouvrez http://192.168.4.1 pour restaurer ou saisir la configuration.
