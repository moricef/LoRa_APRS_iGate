Installation complète uniquement : téléchargez d'abord la sauvegarde JSON depuis la WebConfig. Cette opération efface la configuration et la remplace par les valeurs par défaut.

Installation

  1. Fermez le moniteur série et tout logiciel utilisant le port USB.
  2. Reliez la carte au PC avec un câble USB de données.
  3. Cliquez sur Mettre à jour, puis choisissez le port série de l'ESP32.
  4. Après le redémarrage, ouvrez http://192.168.4.1 depuis le Wi-Fi de configuration de la station.
